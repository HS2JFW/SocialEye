# คู่มือเกณฑ์และรูบริกการประเมินคุณธรรม 5 ด้าน (Moral Rubric)
## โครงการ SocialEye — ระบบเฝ้าระวังคุณธรรมจากสื่อและโซเชียลมีเดีย

> **หมายเหตุสำคัญ:** ดัชนีที่คำนวณจากระบบนี้คือ **"ดัชนีสะท้อนจากสื่อออนไลน์" (Online Media Reflection Index)** เพื่อสะท้อนภาพพฤติกรรม เหตุการณ์ และความคิดเห็นที่ปรากฏบนพื้นที่ออนไลน์ ไม่ใช่การประเมินระดับคุณธรรมส่วนบุคคลของประชาชน

---

## 1. สเกลคะแนนรายตัวละคร (−2 ถึง +2)
ประเมินแต่ละด้านด้วยคะแนนจำนวนเต็มตั้งแต่ `-2` ถึง `+2`:
- **`+2` (ส่งเสริมชัดเจน)**: แบบอย่างที่ดีเด่น การกระทำเชิงรุก หรือสร้างผลกระทบเชิงบวกในวงกว้าง
- **`+1` (สอดคล้อง)**: ปฏิบัติตามคุณธรรมในระดับทั่วไป หรือเป็นประเด็นรองในข่าว
- **`0` (ไม่เกี่ยวข้อง)**: ไม่ปรากฏข้อมูลหรือพฤติกรรมที่เกี่ยวข้องกับคุณธรรมด้านนั้น
- **`-1` (บกพร่อง)**: ละเมิดหรือขัดแย้งกับคุณธรรมในระดับบุคคล/วงจำกัด
- **`-2` (ละเมิดรุนแรง)**: การกระทำผิดร้ายแรง ทุจริตเชิงโครงสร้าง หรือสร้างความเสียหายต่อสังคมและสิ่งแวดล้อมในวงกว้าง

## 2. เกณฑ์การประเมินและกฎแยกแยะรายด้าน (Evaluation Rubrics & Boundary Rules)

### 2.1 พอเพียง (`sufficiency`)
- **นิยาม:** ความสมดุล การใช้เหตุผล การบริหารทรัพยากรอย่างคุ้มค่าและยั่งยืน การสร้างภูมิคุ้มกันต่อความเสี่ยง และการไม่เบียดเบียนตนเอง ผู้อื่น และสิ่งแวดล้อม
- **`+2`:** แบบอย่างความยั่งยืนเชิงระบบ (เช่น Zero Waste, ESG), พึ่งพาตนเอง, จัดการวิกฤตด้วยความรู้จนเกิดผลดีวงกว้าง
- **`+1`:** พฤติกรรมพอประมาณ ประหยัด ออมเงิน รณรงค์ลดใช้ทรัพยากรระดับบุคคล/กลุ่มย่อย
- **`-1`:** ฟุ่มเฟือย บริโภคนิยมเกินตัว ก่อหนี้เกินจำเป็น ใช้ทรัพยากรสิ้นเปลืองในวงจำกัด
- **`-2`:** โลภอย่างรุนแรง กักตุนสินค้า โก่งราคา แชร์ลูกโซ่/พนันออนไลน์ ผลาญทรัพยากรธรรมชาติเพื่อกำไรสูงสุด
- **กฎแยกแยะ:** ห้ามผูกติดกับคำว่า "เกษตรกรรม" หรือ "ความยากจน" หากธุรกิจใหญ่บริหารอย่างยั่งยืนและไม่เอาเปรียบ ให้เป็น `+`

### 2.2 วินัย (`discipline`)
- **นิยาม:** การเคารพกฎหมาย กติกา ระเบียบสังคม จรรยาบรรณวิชาชีพ มาตรฐานความปลอดภัย และความรับผิดชอบต่อผลกระทบ
- **`+2`:** รักษามาตรฐาน/จรรยาบรรณอย่างเคร่งครัดจนเป็นแบบอย่าง หรือยอมรับผิดและเยียวยาความเสียหายเชิงรุกทันที
- **`+1`:** ปฏิบัติตามกฎหมาย กฎจราจร ระเบียบสังคม หรือทำหน้าที่ตามมาตรฐานวิชาชีพปกติ
- **`-1`:** ละเมิดกฎระเบียบ กฎจราจร หรือละเลยหน้าที่ด้วยความประมาท/มักง่าย ผลกระทบวงจำกัด
- **`-2`:** ฝ่าฝืนกฎหมาย มาตรฐานความปลอดภัย หรือจรรยาบรรณร้ายแรงจนสูญเสียชีวิต ทรัพย์สิน หรือสิ่งแวดล้อมวงกว้าง (เช่น เมาแล้วขับชนคนตาย, ปล่อยน้ำเสีย, อาคารถล่ม)
- **กฎแยกแยะ:** ทำผิดกฎเพราะ *ประมาท/มักง่าย* = `discipline (-)` แต่ถ้าทำผิดกฎเพื่อ *โกง/รับสินบน/ผลประโยชน์ทับซ้อน* = `integrity (-)`

### 2.3 สุจริต (`integrity`)
- **นิยาม:** ความซื่อสัตย์ โปร่งใส เป็นธรรม ยึดมั่นในความจริง และการต่อต้านการทุจริตทุกรูปแบบ
- **`+2`:** ยืนหยัดรักษาความจริง เปิดโปงทุจริต (Whistleblower) ปฏิเสธสินบน เก็บของมีค่าคืนเจ้าของ ตัดสินคดีเที่ยงธรรม
- **`+1`:** แสดงความซื่อสัตย์ เปิดเผยข้อมูลโปร่งใส ทำ Fact-checking ค้าขายตรงไปตรงมา
- **`-1`:** ไม่ตรงไปตรงมา โฆษณาเกินจริงระดับบุคคล ลักขโมยเล็กน้อย ใช้เส้นสายในกลุ่มย่อย
- **`-2`:** คอร์รัปชัน ฮั้วประมูล รับสินบน แก๊งคอลเซ็นเตอร์ ฉ้อโกงประชาชน ปลอมแปลงเอกสาร สร้าง Fake News กระทบสังคมวงกว้าง
- **กฎแยกแยะ:** อาชญากรรมเกี่ยวกับทรัพย์ (ลักทรัพย์ ฉ้อโกง ยักยอก) และข่าวปลอม = `integrity (-)`

### 2.4 จิตอาสา (`public_mind`)
- **นิยาม:** การเสียสละเวลา แรงกาย หรือทรัพย์สินส่วนตัวเพื่อช่วยเหลือผู้อื่นและส่วนรวมโดยสมัครใจ ไม่หวังผลตอบแทน และไม่ใช่งานในหน้าที่ปกติ
- **`+2`:** เสียสละสูงช่วยสังคมในภาวะวิกฤต (กู้ภัย, พลเมืองดีเสี่ยงอันตรายช่วยชีวิต/จับโจร, บริจาคอวัยวะ/ทุนทรัพย์ใหญ่)
- **`+1`:** ช่วยเหลือ แบ่งปัน ทำกิจกรรมสาธารณประโยชน์ทั่วไป (บริจาคเลือด เก็บขยะ ปลูกป่า แบ่งปันอาหาร)
- **`-1`:** นิ่งดูดายต่อความเดือดร้อน (Bystander Effect) ถ่ายคลิปประจานแทนการช่วย เห็นแก่ตัวเบียดเบียนพื้นที่ส่วนรวม
- **`-2`:** ขัดขวางการช่วยเหลือสาธารณะ (ขวางรถพยาบาล) ซ้ำเติมผู้ประสบภัย แอบอ้างรับบริจาคเพื่อยักยอก
- **กฎแยกแยะ:** แยก "หน้าที่" ออกจาก "จิตอาสา" — เจ้าหน้าที่ทำงานในเวลาราชการตามหน้าที่ = `discipline (+1)` แต่หากทำเกินหน้าที่ เสียสละส่วนตัว หรือเป็นประชาชนทั่วไปเข้าช่วย = `public_mind (+)`

### 2.5 กตัญญู (`gratitude`)
- **นิยาม:** ความสำนึกรู้คุณและตอบแทนอย่างถูกต้องดีงามต่อผู้มีพระคุณ (บิดามารดา ญาติผู้ใหญ่ ครู) สถาบัน องค์กร แผ่นดินเกิด และธรรมชาติ
- **`+2`:** ตอบแทนคุณอย่างทุ่มเทเป็นรูปธรรม (ดูแลพ่อแม่ป่วยติดเตียง, ศิษย์เก่าสร้างอาคารให้โรงเรียน/บ้านเกิด, ปกป้องผืนป่าด้วยสำนึกรู้คุณ)
- **`+1`:** แสดงความเคารพ ระลึกถึงบุญคุณ ดูแลผู้สูงอายุในครอบครัว ไหว้ครู ขอบคุณแผ่นดินเกิด
- **`-1`:** ละเลยผู้มีพระคุณ ไม่ให้เกียรติครู/ผู้ใหญ่ ใช้ประโยชน์จากชุมชนโดยไม่ดูแลตอบแทน
- **`-2`:** เนรคุณ ทำร้ายหรือทอดทิ้งบิดามารดาอย่างทารุณ จงใจทำลายโบราณสถาน/ทรัพยากรของชาติ ทรยศผู้เคยอุปการะอย่างร้ายแรง
- **กฎแยกแยะ:** แยกจาก `public_mind` ด้วย "สายสัมพันธ์เดิม" — ช่วยคนแปลกหน้า = `public_mind` แต่ตอบแทนพ่อแม่ ครู บ้านเกิด องค์กรที่เคยอยู่ หรือธรรมชาติที่หล่อเลี้ยงชีวิต = `gratitude`

## 3. กฎหลักในการวิเคราะห์ (Core Analysis Rules)
1. **Entity-Level Scoring:** แยกประเมินตามตัวละคร/องค์กรในข่าว ห้ามนำคะแนนบวกของฝ่ายหนึ่งไปหักล้างคะแนนลบของอีกฝ่ายหนึ่ง
2. **Multi-Labeling:** ตัวละคร 1 ตัว หรือข่าว 1 ชิ้น สามารถมีคะแนนได้มากกว่า 1 ด้านพร้อมกัน
3. **Evidence-First:** ต้องดึงข้อความจริงจากข่าว (verbatim quote) มาเป็นหลักฐานก่อนสรุปคะแนนทุกครั้ง
4. **Default to 0:** หากไม่มีหลักฐานชัดเจนในข่าว ให้ใส่คะแนน `0` เสมอ ห้ามคาดเดาหรือตีความเกินเนื้อข่าว

## 4. การแปลงสเกลดัชนีรวม (0.00 - 5.00)
สูตรการแปลงค่าเฉลี่ยถ่วงน้ำหนักจาก Entity-Level Scores ($\bar{x} \in [-2, +2]$):

$$\text{Moral Index} = \left(\frac{\bar{x} + 2}{4}\right) \times 5.00$$

- **`0.00 - 1.50`**: วิกฤตคุณธรรม
- **`1.51 - 2.49`**: เฝ้าระวังเชิงลบ
- **`2.50`**: ระดับสมดุล / เป็นกลาง (Neutral Baseline)
- **`2.51 - 3.50`**: พัฒนาการเชิงบวก
- **`3.51 - 5.00`**: โดดเด่น / สังคมคุณธรรมต้นแบบ
