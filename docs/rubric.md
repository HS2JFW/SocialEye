# คู่มือเกณฑ์และรูบริกการประเมินคุณธรรม 5 ด้าน (Moral Rubric)
## โครงการ SocialEye — ระบบเฝ้าระวังคุณธรรมจากสื่อและโซเชียลมีเดีย

> **หมายเหตุสำคัญ:** ดัชนีที่คำนวณจากระบบนี้คือ **"ดัชนีสะท้อนจากสื่อออนไลน์" (Online Media Reflection Index)** เพื่อสะท้อนภาพพฤติกรรม เหตุการณ์ และความคิดเห็นที่ปรากฏบนพื้นที่ออนไลน์ ไม่ใช่การประเมินระดับคุณธรรมส่วนบุคคลของประชาชน

---

### 1. นิยามคุณธรรม 5 ประการ (อ้างอิงศูนย์คุณธรรม (องค์การมหาชน))
ตามแผนปฏิบัติการด้านการส่งเสริมคุณธรรมแห่งชาติ ระยะที่ 2 (พ.ศ. 2566 - 2570) คุณธรรม 5 ประการประกอบด้วย:

1. **พอเพียง (Sufficiency)**: การดำรงชีวิตอย่างพอประมาณ มีเหตุผล มีภูมิคุ้มกัน ไม่โลภ ไม่เบียดเบียนตนเอง ผู้อื่น และสิ่งแวดล้อม ซื่อตรงต่อการประกอบอาชีพ ไม่กู้หนี้ยืมสินเกินตัว ไม่ฟุ้งเฟ้อ
2. **วินัย (Discipline)**: การเคารพกฎหมาย กติกา ระเบียบสังคม จรรยาบรรณวิชาชีพ การตรงต่อเวลา ความรับผิดชอบต่อหน้าที่พลเมือง และการคำนึงถึงความปลอดภัยส่วนรวม
3. **สุจริต (Integrity)**: ความซื่อสัตย์สุจริต ยืนหยัดในความถูกต้อง ไม่ทุจริตคอร์รัปชัน ไม่รับสินบน ไม่ใช้อำนาจหน้าที่เพื่อประโยชน์ส่วนตนหรือพวกพ้อง ต่อต้านการคดโกงทุกรูปแบบ
4. **จิตอาสา (Public Mind)**: การเสียสละประโยชน์ส่วนตนเพื่อประโยชน์ส่วนรวม การช่วยเหลือผู้ยากไร้ ผู้ประสบภัย บำเพ็ญสาธารณประโยชน์ การอนุรักษ์ธรรมชาติโดยไม่หวังผลตอบแทน
5. **กตัญญู (Gratitude)**: การรู้คุณและตอบแทนบุญคุณต่อบิดามารดา ครูอาจารย์ ผู้มีพระคุณ องค์กร ชุมชน ธรรมชาติสิ่งแวดล้อม และผืนแผ่นดินไทย

### 2. สเกลคะแนนรายชิ้น (−2 ถึง +2)

แต่ละชิ้นเนื้อหาจะได้รับการประเมินแยกทั้ง 5 ด้านอย่างอิสระ:
- **`relevant` (จริง/เท็จ)**: เนื้อหามีประเด็นที่แตะหรือสะท้อนถึงมิตินี้หรือไม่ (หากไม่เกี่ยวข้อง ให้ `relevant: false`, `polarity: 0`)
- **`polarity`**:
  - `+2` (**ส่งเสริมอย่างเด่นชัด / เป็นแบบอย่างยอดเยี่ยม**): การทำความดีที่สร้างผลกระทบกว้างขวาง เป็นต้นแบบที่สังคมชื่นชม
  - `+1` (**ส่งเสริม / เป็นพฤติกรรมเชิงบวก**): การปฏิบัติตามคุณธรรมตามบทบาทหน้าที่ การช่วยเหลือเกื้อกูลทั่วไป
  - `0` (**เป็นกลาง / ไม่เกี่ยวข้องโดยตรง**): รายงานข้อเท็จจริงทั่วไปโดยไม่มีนัยยะทางคุณธรรม
  - `-1` (**บั่นทอน / ฝ่าฝืนระดับทั่วไป**): การละเลยหน้าที่ การกระทำที่ขัดต่อกฎระเบียบหรือความเหมาะสม
  - `-2` (**บั่นทอนรุนแรง / สร้างความเสียหายร้ายแรงต่อสังคม**): คดีคอร์รัปชันร้ายแรง การฉ้อโกงประชาชน การทำร้ายผู้มีพระคุณ การไร้วินัยที่นำไปสู่อันตรายถึงชีวิต

### 3. การแปลงสเกลดัชนีรวม (0.00 - 5.00)
สูตรการแปลงค่าเฉลี่ยถ่วงน้ำหนัก ($\bar{x} \in [-2, +2]$):

$$\text{Moral Index} = \left(\frac{\bar{x} + 2}{4}\right) \times 5.00$$

- **`0.00 - 1.50`**: วิกฤตคุณธรรม (มีพฤติกรรมบั่นทอนสูงมาก)
- **`1.51 - 2.49`**: เฝ้าระวังเชิงลบ (มีข่าวเชิงลบมากกว่าเชิงบวก)
- **`2.50`**: ระดับสมดุล / เป็นกลาง (Neutral Baseline)
- **`2.51 - 3.50`**: พัฒนาการเชิงบวก (มีข่าวส่งเสริมคุณธรรมสม่ำเสมอ)
- **`3.51 - 5.00`**: โดดเด่น / สังคมคุณธรรมต้นแบบ

### 4. กฎสำหรับกรณีซับซ้อนและกำกวม (Ambiguity Rules)
1. **ข่าวปราบปรามทุจริต / จับกุมเจ้าหน้าที่รับสินบน**:
   - ด้าน **สุจริต**: `-2` หรือ `-1` (สะท้อนพฤติกรรมทุจริตที่มีอยู่จริง)
   - ด้าน **วินัย**: `+1` หรือ `+2` (สะท้อนการบังคับใช้กฎหมายอย่างเข้มงวดและมีประสิทธิภาพ)
2. **ข่าวอุบัติเหตุจราจรจากความประมาท / ดื่มแล้วขับ**:
   - ด้าน **วินัย**: `-2` (การละเลยกฎหมายและความปลอดภัยส่วนรวม)
3. **ข่าวระดมทุนช่วยเหลือผู้ประสบภัย / กู้ภัย**:
   - ด้าน **จิตอาสา**: `+2`
   - ด้าน **พอเพียง**: อาจสะท้อนความร่วมมือเกื้อกูล `+1` (หากไม่มีประเด็นเรี่ยไรไม่โปร่งใส)
4. **เนื้อหาเสียดสี (Satire) / มุกตลก / ข่าวปลอม (Unverified)**:
   - ติดธง `flags: ["satire"]` หรือ `flags: ["unverified"]`
   - ข่าวที่ติดธง `unverified` จะถูกลดน้ำหนักถ่วง (weight) เหลือครึ่งหนึ่ง (0.5) ในการคำนวณดัชนีรวม
